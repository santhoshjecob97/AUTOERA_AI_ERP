## **📄 PHASE 1: COMPANY REGISTRATION (Week 1)**

### **Step 1: Name Reservation**
```bash
Company Name Options:
1. AUTOERA AI TECHNOLOGIES PRIVATE LIMITED
2. AUTOERA AUTOMOTIVE AI PRIVATE LIMITED
3. AUTOERA TECH SOLUTIONS PRIVATE LIMITED

Process:
✅ Check name availability on MCA portal
✅ Reserve name (Form INC-1)
✅ Get name approval (1-2 days)
✅ Alternative names ready
```

### **Step 2: Digital Signature Certificates (DSC)**
```bash
Requirements:
✅ Individual DSC for all directors
✅ Class 3 DSC for company incorporation
✅ Valid for 2 years
✅ Cost: ₹1,000-2,000 per DSC

Documents Needed:
• PAN Card copy
• Aadhaar Card copy
• Passport size photo
• Email ID and mobile number
```

### **Step 3: Director Identification Number (DIN)**
```bash
Process:
✅ Apply for DIN (Form DIR-3)
✅ All directors need separate DIN
✅ Cost: ₹500 per DIN
✅ Processing time: 1-2 days

Documents Required:
• PAN Card
• Aadhaar Card
• Passport size photos
• Address proof
• Mobile and email verification
```

### **Step 4: Company Incorporation**
```bash
Form: SPICe (INC-32)
✅ Memorandum of Association (MoA)
✅ Articles of Association (AoA)
✅ INC-9 Declaration
✅ Director consent forms
✅ Registered office proof

Processing Time: 3-5 days
Cost: ₹5,000-10,000 (including stamp duty)
```
