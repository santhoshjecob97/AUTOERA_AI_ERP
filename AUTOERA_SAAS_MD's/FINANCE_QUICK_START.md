# Finance AI Engine - Quick Start Guide

## 🚀 Getting Started

### Access the Finance Engine
1. Start the development server: `npm run dev`
2. Navigate to: `http://localhost:5173/finance`
3. Click on any tab to explore the pages

---

### 1. Credit Scoring (`/finance/credit-scoring`)
**Purpose:** AI-powered credit assessment in 2-3 seconds  
**Key Features:** Score visualization, breakdown analysis, loan recommendations

### 2. Loan Approval (`/finance/loan-approval`)
