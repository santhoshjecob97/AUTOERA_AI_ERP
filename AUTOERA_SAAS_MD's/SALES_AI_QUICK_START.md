# Sales AI Engine - Quick Start Guide

## 🚀 Getting Started

### Access the Sales AI Engine
Navigate to: **`/sales`**

### Available Pages
1. **Overview** (`/sales`) - Main dashboard
2. **Leads** (`/sales/leads`) - Lead management
3. **Virtual Showroom** (`/sales/showroom`) - Vehicle customization
4. **Pricing** (`/sales/pricing`) - Dynamic pricing
5. **Chatbot** (`/sales/chatbot`) - Conversation monitoring
6. **Analytics** (`/sales/analytics`) - Performance metrics

---

## 📊 Quick Feature Guide

### Leads Page
- **View by Category**: Hot (85-100), Warm (60-84), Cool (40-59), Cold (0-39)
- **Search**: Type name or vehicle
- **Filter**: By status (New, Contacted, Negotiation, Closed)
- **Call**: Click phone icon on any lead card
- **Bulk Campaign**: Use Voice AI section at bottom

### Virtual Showroom
- **Select Vehicle**: Choose from 5 premium models
- **Customize**: Pick colors, interior, wheels, packages
- **Watch Pricing**: Updates in real-time
- **AI Recommendations**: See suggested upgrades
- **Save/Share**: Generate quotes

### Pricing Page
- **Select Vehicle**: Choose model to price
- **Adjust Discount**: Use slider (0-10%)
- **View Impact**: Conversion, revenue, margin, time-to-sale
- **Compare**: See competitor prices
- **Apply**: Use AI-suggested pricing

### Chatbot Page
- **Select Conversation**: Click on any active chat
- **View History**: See full conversation
- **Check Intent**: AI-detected customer intent
- **Lead Score**: Real-time qualification
- **Take Over**: Human handoff when needed

### Analytics Page
- **KPIs**: Conversion rate, deal value, pipeline, AI impact
- **Funnel**: See lead progression
- **Trends**: 7-day sales chart
- **Team**: Performance rankings
- **AI Metrics**: Model effectiveness

## 🎯 Common Tasks

### Make a Voice Call
1. Go to Leads page
2. Find lead card
3. Click phone icon
4. Call modal opens
5. Initiate call

### Customize a Vehicle
1. Go to Virtual Showroom
2. Select vehicle
3. Choose colors and options
4. Watch price update
5. Generate quote

### Check Team Performance
1. Go to Analytics page
2. Scroll to Team Performance table
3. See rankings and metrics
4. Export if needed

### Monitor Chatbot
1. Go to Chatbot page
2. View active conversations
3. Check lead scores
4. Take over if needed

## 💡 Tips

- **Bulk Campaigns**: Use for efficient outreach
- **Time Period**: Change in Analytics for different views

## 🎨 Color Guide

- 🔴 **Red/Hot**: High priority (85-100)
- 🟠 **Orange/Warm**: Medium priority (60-84)
- 🔵 **Blue/Cool**: Low priority (40-59)
- ⚪ **Gray/Cold**: Very low priority (0-39)
