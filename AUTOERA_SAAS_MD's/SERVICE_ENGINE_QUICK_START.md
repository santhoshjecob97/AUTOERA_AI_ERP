## Common Actions

### Add a New Service Job
1. Click "New Job Card"
2. Fill in customer details
3. Select vehicle and issue
4. Assign technician and bay
5. Click "Add Job"

### Make a Voice Call
1. Find a job in the Operations tab
2. Click the phone icon in the Actions column
3. Voice modal opens with customer context
4. Start conversation

### Run a Bulk Voice Campaign
1. Go to Comm. & Voice tab
2. Click "Bulk Campaigns" sub-tab
3. Click "Upload CSV" or "Connect Google Sheets"
4. Configure campaign settings
5. Launch campaign

### Import Multiple Jobs
1. Click "Import Jobs" button
2. Download sample CSV template
3. Fill in your data
4. Upload CSV file
5. Review and confirm import

### Check Quality Metrics
1. Go to Quality & CX tab
2. Click "Feedback Intelligence"
3. View NPS score and sentiment analysis
4. Check category performance
5. Read AI-analyzed reviews

## Troubleshooting

### If tabs don't switch:
- **Refresh the browser** (Ctrl+R or Cmd+R)
- Clear browser cache
- Check browser console for errors

### If modals don't open:
- Ensure JavaScript is enabled
- Check for browser extensions blocking modals
- Try a different browser

### If charts don't render:
- Wait a moment for data to load
- Refresh the page
- Check network connection
