## 📊 **Database Schema**

### **Core Models**
```python
# Customer Model
class Customer:
    - id, name, phone, email
    - vehicle_model, vehicle_year, registration
    - address, city, state, pincode
    - loyalty_score, segment, preferences
    - preferred_contact_method
    - last_call_date, call_count (NEW)
    - created_at, updated_at

# Service Appointment
class ServiceAppointment:
    - id, customer, service_type, status
    - scheduled_date, estimated_duration
    - assigned_bay, assigned_technician
    - estimated_cost, actual_cost
    - notes, completion_status
    - booked_via (voice_call, web, mobile) (NEW)

# Service Bay
class ServiceBay:
    - id, name, bay_type, capacity
    - current_status, utilization_rate
    - equipment_list, technician_skills_required
    - location, availability_schedule

# AI Prediction
class AIPrediction:
    - id, prediction_type, confidence_score
    - input_data, output_result
    - model_version, created_at
    - validation_status, accuracy_score

# Communication Log
class CommunicationLog:
    - id, customer, channel_type, message_content
    - sent_at, delivery_status, response_received
    - campaign_id, template_used
    - call_sid, call_duration (NEW)

# Voice Call Record (NEW)
class VoiceCallRecord:
    - id, call_sid, customer, phone_number
    - call_type (outbound, inbound)
    - call_status (initiated, answered, completed, failed)
    - call_duration, recording_url
    - conversation_state, booking_status
    - sentiment_score, conversion_status
    - follow_up_scheduled, notes
    - created_at, updated_at
```
