# HISTORICAL ENGINEERING RECORDS

This directory contains documentation from earlier AutoEra AI ERP development stages.

These documents record development decisions, test results, and architectural plans
from the engineering process. They are preserved for historical reference.

## ⚠️ IMPORTANT

These documents are **NOT** evidence of current production deployment status.

Current production status must be determined from runtime verification in:
`docs/current/`

## Directory Structure
- `core/` — Architecture, API specs, RBAC, tenant isolation docs
- `stage5b/` — Initial quality audits
- `stage6a/` — ERP module coverage audits
- `stage6b/` — RAG engine development
- `stage6c/` — AI agent orchestration
- `stage6d/` — Voice, telephony, pgvector, multilingual
- `stage7/` — Deployment preparation, pilot planning
