# 05 — Database Production Readiness

**Target DBMS**: PostgreSQL 16+ on Render  
**Configuration Driver**: `psycopg2-binary` (v2.9.9) + `django-environ` (v0.11.2)

---

## 1. Connection Pool & Performance Tuning

- `CONN_MAX_AGE`: 600 seconds for persistent connections.
- `connect_timeout`: 10 seconds.
- Transaction management: Atomic transaction decorators on multi-step ERP operations (Job Card closure, Parts deduction, Invoice issuance).

---

## 2. pgvector & Vector Search Readiness

- In `backend/ai_platform/models.py`, `KnowledgeChunk` stores 768-dimensional embeddings generated by `models/gemini-embedding-2`.
- Hybrid retrieval combines full-text search (`SearchVector`, `SearchQuery`) with dense vector cosine similarity when pgvector is loaded in PostgreSQL.
- Fallback mode: If pgvector is unavailable or in development SQLite mode, hybrid search gracefully falls back to structured keyword + metadata filtering with exact semantic ranking.
