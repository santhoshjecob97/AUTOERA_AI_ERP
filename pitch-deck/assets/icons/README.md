## Design Specifications

### Style Guidelines
- **Line Weight**: 2px stroke
- **Style**: Outlined with rounded caps
- **Size**: 24px, 32px, 48px variants
- **Color**: Autoera Blue (#1E3A8A) primary, Innovation Orange (#F97316) for highlights
- **Format**: SVG for scalability

### Usage Guidelines
- Use consistent sizing within each slide
- Maintain proper contrast with backgrounds
- Apply brand colors consistently
- Ensure accessibility with sufficient contrast ratios

## File Naming Convention

```
[category]-[name]-[size].svg

Examples:
- automotive-car-24.svg
- ai-brain-32.svg
- business-growth-48.svg
```

## Implementation

### HTML Usage
```html
<img src="assets/icons/automotive-car-24.svg" alt="Car" class="icon-small">
<img src="assets/icons/ai-brain-32.svg" alt="AI" class="icon-medium">
<img src="assets/icons/business-growth-48.svg" alt="Growth" class="icon-large">
```

### CSS Classes
```css
.icon-small { width: 24px; height: 24px; }
.icon-medium { width: 32px; height: 32px; }
.icon-large { width: 48px; height: 48px; }
```
